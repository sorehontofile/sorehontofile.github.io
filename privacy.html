プライバシーポリシー

最終更新日：2026年11月19日

sorehonto-uploader（以下「本ツール」）は、YouTube チャンネル「それ、ホント?ファイル」の運営者が、自分の動画を自分のチャンネルにアップロードするためだけに使う個人用ツールです。

1. 使用する Google のデータ

本ツールは、運営者本人の Google アカウントで許可を得て、YouTube API Services の次の権限だけを使います。

  • 動画のアップロード（youtube.upload）
  • 自分のチャンネル情報とアップロードした動画の公開状態の確認（youtube.readonly）

また、完成した動画を運営者自身のスマートフォンに渡すため、Google ドライブの次の権限を使います。

  • 本ツールが作成したファイルだけの作成・更新（drive.file）。本ツールが作っていないドライブのファイルは読みません

2. データの保存

許可によって得られる認証情報（トークン）は、運営者のパソコンの中だけに保存します。外部のサーバーには送信・保存しません。

3. 第三者への提供

取得したデータを第三者に提供・販売・共有することはありません。広告や分析の目的にも使いません。

4. 許可の取り消し

Google アカウントのセキュリティ設定（サードパーティのアクセス）から、いつでも本ツールへの許可を取り消せます。取り消すと、パソコンに保存した認証情報も使えなくなります。

5. YouTube と Google のポリシー

本ツールは YouTube API Services を使用しています。本ツールの利用には YouTube 利用規約 が適用されます。Google によるデータの取り扱いについては Google プライバシーポリシー をご覧ください。

6. お問い合わせ

YouTube チャンネル「それ、ホント?ファイル」までお寄せください。
